# Accessibility

Pancake Compressor aims for WCAG 2.2 AA where relevant to the desktop interface: keyboard access, visible focus, proper labels/status announcements, high contrast, 200% scaling, reduced motion and colour-independent statuses.

**Status:** design requirement, not yet assessed on released native builds. Read `docs/12-accessibility-and-design-system.md`, `docs/23-ui-ux-flows-performance-v3.md` and `docs/IMPLEMENTATION-STATUS.md` for evidence.

Please report barriers through GitHub Issues, choosing the bug or accessibility label when available. Share your OS, keyboard/screen reader, expected result and steps, without including sensitive images.
