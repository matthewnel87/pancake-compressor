# Reviews, feedback and suggestions

Pancake Compressor is built in public. Useful feedback doesn't require programming skills.

- **General feedback / what feels good or awkward:** GitHub Discussions → `Feedback & Reviews` (maintainers must enable and create this category).
- **Ideas for features:** Discussions → `Feature Ideas` or the feature-request form if actionable.
- **Something broken:** Issues → `Bug report`; include app version, OS/processor, format, steps, expected and actual results.
- **Docs are unclear:** Issues → `Documentation issue`.
- **A security vulnerability:** GitHub Security → private report; **never post exploit details publicly**.
- **Contribute code or design:** read `CONTRIBUTING.md` and open a small pull request, especially against `good first issue`.

## Privacy when reporting
Only upload sample images you created yourself or may legally redistribute. Remove faces, names, location metadata and filesystem paths. Sanitise screenshots and terminal output. There is no requirement to upload actual private files to receive basic support.

## Friendly review questions
What OS did you install on? Was choosing the right download easy? How many images did you use? Did you understand what Smart Auto did? Could you find the exported images? Was processing clear? Was the brand delightful or distracting? What one thing would you change?

A GitHub star is not a user review/rating. Do not misrepresent stars as validated customer satisfaction.
