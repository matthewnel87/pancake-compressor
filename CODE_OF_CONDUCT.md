# Code of conduct

Be kind, constructive and respectful. Treat first-time users, designers and developers as equally welcome. Critique the work, not the person. Do not harass, intimidate, disclose private information, spam or exploit vulnerable users.

Maintainers may edit or remove harmful submissions and block repeated misconduct. Report conduct concerns privately to maintainers through GitHub contact methods configured for the project; do not post allegations or private details in public issues. Before opening contributions, maintainers must add a clear reachable private moderation contact and a documented procedure in this file.

This is a short project policy starter, not an assertion that a staffed moderation team already exists.
